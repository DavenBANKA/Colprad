# CHARTE GRAPHIQUE COLPRAD

Guide visuel minimal, pensé pour l'événement culturel COLPRAD (site, billetterie, supports imprimés et réseaux).

## Identité visuelle — principes

- **Ton** : chaleureux, accessible, professionnel, ancré dans les arts locaux
- **Usage** : cohérence entre site vitrine, page billetterie, affiches, programmes et posts sociaux
- **Priorité** : lisibilité mobile-first, contraste accessible, cohérence couleur pour signalétique

## Typographie

- **Titres** : "Playfair Display" ou "Merriweather" (serif élégant)
- **Corps de texte** : "Inter" ou "Roboto" (sans-serif lisible)
- **Hiérarchie** :
  - H1: 36–48px (mobile: 32px)
  - H2: 24–32px (mobile: 24px)
  - H3: 18–20px
  - Paragraphe: 16px (mobile: 15px)
- **Interlignage** : 1.25–1.5 selon taille
- **Poids** : titres semi-bold/700 ; corps regular/400 ; légendes italic 300–400

## Composants UI (web / billetterie)

### Header
- Logo gauche
- CTA billetterie droit (bouton Ocre sur Bleu nuit)

### Buttons
- **Primaire (achat)** : Fond Turquoise (#0E5E96), texte blanc, border-radius 8px
- **Secondaire (info)** : Fond transparent, bord Ocre, texte Ocre
- **Taille minimale tactile** : 44×44 px

### Formulaires
- Champs full-width mobile
- Labels persistants
- Validation inline
- Border-radius: 8px

## Accessibilité & contrastes

- Respect contraste WCAG AA minimum : texte normal ratio ≥ 4.5:1 ; large text ≥ 3:1
- Pas de reliance exclusive sur la couleur
- Taille de lien cible tactile ≥ 44×44 px sur mobile

## Ton rédactionnel et microcopy

- **Voix** : claire, conviviale, professionnelle
- **CTA exemples** : "Réserver maintenant", "Voir le programme", "Acheter un billet"
- **Messages d'erreur** : courts et orientés solution
