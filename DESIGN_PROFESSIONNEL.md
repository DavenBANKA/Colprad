# Design Professionnel COLPRAD 2025

## 🎨 Vue d'Ensemble

Le site COLPRAD 2025 a été entièrement repensé pour offrir une expérience professionnelle, élégante et riche en informations, sans utilisation d'icônes superflues. L'accent est mis sur la typographie, la hiérarchie visuelle et le contenu de qualité.

## 🎨 Système de Design

### Typographie

#### Titres (Headings)
- **Font** : Playfair Display (serif élégant)
- **Poids** : 700 (Bold)
- **Utilisation** : Tous les titres H1-H6
- **Caractère** : Professionnel, élégant, culturel

#### Corps de Texte
- **Font** : Inter (sans-serif moderne)
- **Poids** : 300-600
- **Utilisation** : Paragraphes, navigation, boutons
- **Caractère** : Lisible, moderne, accessible

#### Hiérarchie
```
H1: 3.5rem (56px) - Hero titles
H2: 2.5rem (40px) - Section titles
H3: 1.5rem (24px) - Card titles
H4: 1.25rem (20px) - Subsection titles
Body: 1rem (16px) - Regular text
Small: 0.9rem (14px) - Meta information
```

### Palette de Couleurs

#### Couleurs Principales
- **Ivoire** : `#F9F6EF` - Fond principal
- **Bleu Nuit** : `#052B47` - Accent, en-têtes
- **Turquoise** : `#0E5E96` - Primaire, liens
- **Orange** : `#D8431A` - CTA, accents
- **Vert** : `#4E923D` - Success, validation

#### Couleurs Fonctionnelles
- **Texte foncé** : `#2C2C2C` - Corps de texte
- **Texte clair** : `#F9F6EF` - Texte sur fond foncé
- **Gris** : `#666` - Texte secondaire

#### Couleurs Badges
- **VIP** : `#D4AF37` (Or)
- **Premium** : `#9E9E9E` (Argent)
- **Staff** : `#0057A6` (Bleu)
- **Presse** : `#8B0000` (Rouge foncé)

### Composants

#### Cartes (Cards)
- **Border-radius** : 12px
- **Shadow** : `0 4px 20px rgba(0,0,0,0.08)`
- **Hover** : Transform translateY(-8px) + shadow enhanced
- **Padding** : 2.5rem (desktop), 1.5rem (mobile)
- **Border-left** : 4px solid (couleur thématique)

#### Boutons
- **Primary** : Fond turquoise, texte blanc
- **CTA** : Fond orange, texte blanc
- **Outline** : Bordure blanche, fond transparent
- **Border-radius** : 8px
- **Padding** : 1rem 2.5rem
- **Hover** : Transform translateY(-3px) + shadow

#### Badges
- **Border-radius** : 20px (pill shape)
- **Padding** : 0.5rem 1rem
- **Font-weight** : 600
- **Letter-spacing** : 0.3px

#### Sections
- **Padding vertical** : 5rem (80px)
- **Alternance** : bg-white / bg-light
- **Container** : max-width 1140px

### Effets Visuels

#### Gradients
```css
/* Hero gradient */
linear-gradient(135deg, #052B47 0%, #0E5E96 50%, #052B47 100%)

/* CTA gradient */
linear-gradient(135deg, #052B47 0%, #0E5E96 100%)

/* Card header gradient */
linear-gradient(135deg, rgba(14, 94, 150, 0.05) 0%, rgba(14, 94, 150, 0.02) 100%)
```

#### Ombres
```css
/* Soft shadow */
box-shadow: 0 2px 8px rgba(0,0,0,0.06);

/* Medium shadow */
box-shadow: 0 4px 15px rgba(0,0,0,0.1);

/* Strong shadow */
box-shadow: 0 8px 25px rgba(0,0,0,0.15);
```

#### Transitions
```css
/* Standard transition */
transition: all 0.3s ease;

/* Hover lift */
transform: translateY(-5px);
```

#### Backdrop Filter (Glassmorphism)
```css
backdrop-filter: blur(10px);
background: rgba(255,255,255,0.15);
border: 1px solid rgba(255,255,255,0.2);
```

## 📱 Responsive Design

### Breakpoints
- **Mobile** : < 768px
- **Tablet** : 768px - 991px
- **Desktop** : 992px - 1199px
- **Large Desktop** : ≥ 1200px

### Adaptations Mobile

#### En-tête
- Barre supérieure masquée
- Logo réduit (1.3rem)
- Sous-titre masqué
- Menu hamburger

#### Hero
- Titre : 1.8rem (au lieu de 3.5rem)
- Sous-titre : 0.95rem
- Cartes méta : Padding réduit
- Boutons : Full width

#### Cartes
- Padding : 1.5rem (au lieu de 2.5rem)
- Titres : Tailles réduites
- Marges : Optimisées

#### Statistiques
- Chiffres : 2.5rem (au lieu de 3.5rem)
- Layout : 2 colonnes

## ♿ Accessibilité

### Contraste
- **Ratio minimum** : 4.5:1 pour le texte normal
- **Ratio minimum** : 3:1 pour le texte large
- **Vérification** : Tous les textes respectent WCAG AA

### Navigation
- **Focus visible** : Outline sur tous les éléments interactifs
- **Skip links** : Navigation au clavier optimisée
- **ARIA labels** : Sur tous les boutons et liens

### Tailles
- **Texte minimum** : 16px (1rem)
- **Cibles tactiles** : Minimum 44x44px
- **Espacement** : Suffisant entre les éléments cliquables

### Sémantique
- **HTML5** : Structure sémantique correcte
- **Headings** : Hiérarchie logique H1-H6
- **Alt text** : Sur toutes les images (à ajouter)

## 🚀 Performance

### Optimisations
- **Fonts** : Preconnect Google Fonts
- **Images** : Lazy loading (à implémenter)
- **CSS** : Minification en production
- **JS** : Chargement différé des scripts non critiques

### Métriques Cibles
- **First Contentful Paint** : < 1.5s
- **Largest Contentful Paint** : < 2.5s
- **Time to Interactive** : < 3.5s
- **Cumulative Layout Shift** : < 0.1
