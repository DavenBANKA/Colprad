## 🔧 Comment Configurer la Réponse Automatique

### Étape 1 : Installer WhatsApp Business

1. Téléchargez **WhatsApp Business** (pas WhatsApp normal)
2. Installez sur le téléphone qui gère le numéro +228 92 38 40 92
3. Configurez votre profil professionnel

### Étape 2 : Activer les Messages Automatiques

#### Sur Android/iPhone :

1. Ouvrez **WhatsApp Business**
2. Allez dans **Paramètres** (⚙️)
3. Sélectionnez **Outils professionnels**
4. Choisissez **Message d'absence**
5. Activez le bouton
6. Sélectionnez **Toujours envoyer**

### Étape 3 : Configurer le Message

1. Dans **Message d'absence**, cliquez sur **Modifier le message**
2. Copiez-collez le message ci-dessus
3. Cliquez sur **Enregistrer**

### Étape 4 : Tester

1. Envoyez un message test depuis un autre numéro
2. Vérifiez que la réponse automatique arrive
3. Ajustez si nécessaire

## 🔐 Sécurité et Bonnes Pratiques

### ✅ À Faire

- Vérifier chaque paiement avant validation
- Demander le numéro de commande
- Garder une trace de toutes les transactions
- Répondre dans les 2 heures maximum
- Envoyer un message de confirmation après validation

### ❌ À Ne Pas Faire

- Ne jamais donner d'autres numéros de paiement
- Ne pas valider sans preuve de paiement
- Ne pas partager les informations clients
- Ne pas oublier d'envoyer le billet après paiement
