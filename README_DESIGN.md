## 🚀 Démarrage en 3 Étapes

### 1. Activer l'Environnement
```bash
.venv\Scripts\activate
```

### 2. Lancer le Serveur
```bash
python app.py
```

### 3. Ouvrir le Navigateur
```
http://localhost:5000
```

**C'est tout ! Votre site est en ligne localement. 🎉**

## 🆘 Besoin d'Aide ?

### Questions Fréquentes

**Q: Comment changer une couleur ?**
R: Ouvrez `static/css/style.css` et modifiez les variables CSS dans `:root`

**Q: Comment modifier un texte ?**
R: Ouvrez `templates/index.html` et trouvez la section à modifier

**Q: Le serveur ne démarre pas ?**
R: Vérifiez que l'environnement virtuel est activé et que les dépendances sont installées

**Q: Les styles ne s'appliquent pas ?**
R: Videz le cache du navigateur (Ctrl + Shift + R)
